# rupu-skills

Offensive-security Agent Skills in the [agentskills.io](https://agentskills.io) `SKILL.md` format, for authorized security assessments. Each skill is a self-contained directory under `skills/` that imports into rupu — or any agentskills.io-compatible client — like any general skill.

Skills teach methodology and full tool use. Scope and authorization are the operator's and the platform's responsibility, not the skill's.
